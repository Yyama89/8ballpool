# Pool External Panel

Aplicativo Android independente com painel flutuante simples. Não lê memória, não injeta código e não controla o 8 Ball Pool.

## Compilação automática
O workflow `.github/workflows/build-apk.yml` compila o APK de debug pelo GitHub Actions e publica o arquivo como artifact.

## Permissões
Na primeira ativação, o Android solicitará permissão **Exibir sobre outros apps**. Autorize para mostrar o painel.

## Limites desta versão
Esta versão contém somente o painel flutuante: arrastar, minimizar/restaurar e fechar. Não inclui mira, leitura de tela ou previsão de trajetória.
